# README Conventions

- Never guess the **intended audience**; ask the user to specify it before drafting.
- Prefer **scannable schematic structures** (lists, tables, headings) over dense paragraphs.
- Keep **list items concise** (a single short sentence per item); never embed multi-sentence narrative paragraphs or multiple topics in one bullet.
- Use **capability-first structure**: lead each entry with a specific, factual sentence stating the outcome the reader gains (e.g., "consistent, automatically enforced code style on every commit", not "better code quality" and never leading with file or tool names), followed by the tools or files that deliver it.
