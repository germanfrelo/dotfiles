# dotfiles

> My [dotfiles](https://dotfiles.github.io/) across multiple machines, managed with [chezmoi](https://www.chezmoi.io/).

## Supported OS

- macOS

## Managed machine types

- `personal`
- `work`

They are configured using the custom data variable `machine_type` in [`home/.chezmoi.toml.tmpl`][chezmoi-config-file].

## Managed files

- **Source files:** see [`home/`][home].
- **Target files:** see [MANAGED.txt][managed-txt] (relative to the `$HOME/` directory of the local machine).

## Configuration deviations from chezmoi defaults

| Configuration    | Default                  | Deviation                         | Configured in                                    |
| ---------------- | ------------------------ | --------------------------------- | ------------------------------------------------ |
| Source directory | `~/.local/share/chezmoi` | A custom path                     | [`home/.chezmoi.toml.tmpl`][chezmoi-config-file] |
| Source root      | Root of this repo        | `home/` subdirectory of this repo | [`.chezmoiroot`][chezmoi-root]                   |

## Custom automations

### Always-current managed file list

[MANAGED.txt][managed-txt] is a generated file that lists all target files in the local `$HOME/` directory **currently** managed in this repo.

It is automatically regenerated by [`scripts/managed.js`][managed-js] and [`.husky/pre-commit`][pre-commit-hook] whenever source files (in [`home/`][home]) are staged, ensuring it is always up-to-date with the current source state.

It can also be manually regenerated by running the npm script command `npm run managed` (see [package.json][package-json]).

## Installation

Install this dotfiles repo:

```sh
chezmoi init germanfrelo
```

Install dependencies:

```sh
npm install
```
