# dotfiles

My [dotfiles](https://dotfiles.github.io/) across multiple machines, managed with [chezmoi][url-chezmoi].

## Overview

> [!IMPORTANT]
> This repository is designed explicitly for **macOS**.

It manages two core components of my machines:

1. Software
2. Configuration files

The exact software and dotfiles installed on a given machine depend on its intended use (`personal` or `work`). This behavior is controlled by a custom `machine_type` variable configured in [`home/.chezmoi.toml.tmpl`][file-chezmoi-config]. During the first run of `chezmoi init`, you will be prompted to select your `machine_type`. Chezmoi saves this choice locally (`~/.config/chezmoi/chezmoi.toml`) and uses it to automatically determine which packages and configurations to apply.

### 1. Software

Via **Homebrew**:

- **CLI tools** (`formulae`)
- **GUI apps and fonts** (`casks`)

These packages are controlled **declaratively** by [this setup script][file-script-install-packages]. It runs automatically _before_ chezmoi deploys any dotfiles to ensure Homebrew is installed beforehand. It then evaluates a dynamic `Brewfile` inside the script to install all required packages via `brew bundle install`.

> [!NOTE]
> Removing a package from the template does **not** uninstall it from your system; you must run `brew uninstall <pkg>` manually first.

### 2. Configuration files

The dotfiles that configure the software.

#### Managed files

- **Source files:** in [`home/`][dir-home].
- **Target files:** in the `$HOME/` directory of your local machine. You can see a real-time index/snapshot of them in [`MANAGED.txt`][file-managed-txt], which is automatically (re)generated by [`scripts/managed.js`][file-managed-js] and [`.husky/pre-commit`][file-pre-commit-hook] whenever source files (in [`home/`][dir-home]) are staged. This ensures it is always up-to-date with the current source state without any manual steps. It can also be manually regenerated by running the npm script command `npm run managed` (see [package.json][file-pkg-json]).

#### Configuration deviations from chezmoi defaults

| Configuration    | Default                  | Deviation                         | Configured in                                    |
| ---------------- | ------------------------ | --------------------------------- | ------------------------------------------------ |
| Source directory | `~/.local/share/chezmoi` | A custom path                     | [`home/.chezmoi.toml.tmpl`][file-chezmoi-config] |
| Source root      | Root of this repo        | `home/` subdirectory of this repo | [`.chezmoiroot`][file-chezmoiroot]               |

## Getting started

> [!CAUTION]
> This repo installs software and modifies local configurations. Please read all the details below and ensure you are familiar with [chezmoi][url-chezmoi] before proceeding. Use this only if you understand the implications. **Proceed at your own risk!**

Steps to initialize chezmoi with this repo in your machine:

1. [Install chezmoi][url-chezmoi-install].
2. Follow the quick start guide for [using chezmoi across multiple machines][url-chezmoi-initialize-repo] (see the [`init` command reference][url-chezmoi-ref-init] for deep details).
3. Install repo dependencies: `cd $(chezmoi source-path) && npm install`
4. Restart your machine to ensure all changes take effect.
