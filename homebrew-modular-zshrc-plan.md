# Implementation Plan: Homebrew Modular Machine Configuration & Split Sync

This implementation plan is dedicated to the `homebrew/interactive-split-sync` branch. It defines the modular `machine.zsh.tmpl` architecture so that `.zshrc` remains untemplated, renumbers the Homebrew ADR to ADR 0008, and configures startup drift alerts.

## Goal Description

When merging `repos/script-clone-github-repos` into `main` and then rebasing `homebrew/interactive-split-sync`, we must resolve the architecture for machine-dependent environment variables (`HOMEBREW_BUNDLE_FILE`) without templating the entire 360-line `.zshrc` file. This preserves `chezmoi re-add` functionality and maintains clean separation of concerns.

---

## Proposed Changes

### Component 1: Modular Machine Configuration

#### [NEW] `home/private_dot_config/zsh/machine.zsh.tmpl`

Create a lightweight machine-specific template containing only variables that depend on `.machine_type`:

```zsh
# Machine-specific environment variables dynamically generated by chezmoi.
# DO NOT EDIT DIRECTLY: Managed by chezmoi via machine.zsh.tmpl.

export HOMEBREW_BUNDLE_FILE="${XDG_CONFIG_HOME}/homebrew/{{ .machine_type }}/Brewfile"
```

#### [MODIFY] `home/private_dot_config/zsh/dot_zshrc`

Keep `dot_zshrc` as a plain, untemplated file:

1. Remove any hardcoded `HOMEBREW_BUNDLE_FILE="${XDG_CONFIG_HOME}/homebrew/Brewfile"`.
2. Source `machine.zsh` via zsh4humans right after standard XDG exports:
   ```zsh
   # Machine-specific configuration (generated by chezmoi)
   z4h source "${XDG_CONFIG_HOME}/zsh/machine.zsh"
   ```
3. In the terminal startup block (`if (( SHLVL == 1 ))`), include the Homebrew drift check:
   ```zsh
   # homebrew:
   # Print a warning if Brewfile has uninstalled packages or untracked packages.
   if ! brew bundle check --no-upgrade &>/dev/null; then
       print -P "%F{yellow}homebrew: warning: Brewfile is out of sync with installed packages.%f"
   fi
   ```

### Component 2: Decision Record Renumbering

#### [RENAME & MODIFY] `docs/decisions/0007-homebrew-package-management.md` → `docs/decisions/0008-homebrew-package-management.md`

Because `0007-personal-github-repositories-cloning.md` merges into `main` first, renumber the Homebrew ADR to `0008-homebrew-package-management.md`.
Update its contents to reflect:

- Option 7: Dual Raw Target Files with Startup Drift Alerts.
- Sourcing `machine.zsh.tmpl` rather than templating `.zshrc`.
- Reliance on standard Homebrew environment variable `HOMEBREW_BUNDLE_FILE`.
